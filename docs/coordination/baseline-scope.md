# Snapshot scope

The core composes storage, HomeBox, Network, web, access and media modules.
Contracts define source-qualified identities, explicit revisions, uncertainty
and scoped projections. HomeBox owns inventory/location/file/maintenance data;
Atlas owns identities and reviewed bindings/semantics. Network projections
never establish physical geometry, electrical circuits or valve routes.

Fixtures are synthetic, floorplans are optional and no host, household account,
production import, credential, persistent grant or service is supplied.
This snapshot has a new file manifest and explicit sanitation adaptations.
Historical freezes and private adoption/approval/evidence records remain in
the private coordinator ledger. Reviewed owner corrections are integrated
with new explicit source-presence admission blocked. Final independent new-history
publication audit and scoped release remain required. Ordinary coverage does not
certify full product/security or operational readiness.
