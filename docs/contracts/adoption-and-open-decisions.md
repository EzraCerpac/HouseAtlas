# Contract boundaries and remaining decisions

Contract 1.0.0 / record schema 1 uses opaque UUID identities, per-record integer
revisions and explicit guards. Source-qualified keys remain reserved across
homes in one workspace, including retired/tombstoned bindings. Source edits
use verified native HomeBox navigation; Network remains GET-only.

Evidence, geometry versions and reconciliation journals are append-only.
Retain uncertainty and immutable original asset identity. Geometry is optional
and requires reviewed Magicplan inputs. Names and tree depth never prove floors.
Changes to payload, authority, uniqueness, revision or errors require coordinated
contract/schema/fixture/adapter review. Record revision is not a DB migration.

Deployment decisions are unfilled: audience and language/aliases, host/runtime,
paths/ports/origins, source instance/collection and least-authority access,
native routes, secret storage/recovery, media policy and recovery objectives.
Exceptional wrong-identity reassignment, hard purge, retention, recurrence and
notifications require their own reviewed scope. No gate is released here.

The reviewed core now composes canonical v1 operations and the additive HTTP
1.1.0 history sidecar without changing record schema 1. Transaction-derived
source authority and explicit home DTO fields are integrated. New explicit
source-presence admission remains blocked pending a durable atomic witness
extension. URL filtering is heuristic; full security qualification remains open.
Safe source provenance is described in docs/publication/provenance.md; private
approval and intake records are retained externally by the coordinator.
