# Standalone source provenance

Logical source modules are contracts, operations policy, storage, HomeBox,
Network, web, access, media and core integration. source-manifest.json is the
explicit allowlist of current regular files, modes, byte counts, SHA-256 hashes
and logical ownership. Its own bytes are anchored by independent exact-tree
review, avoiding a circular self-hash. Git history must start from that reviewed
sanitized tree, with an explicitly selected nonprivate publication identity.

The private coordinator ledger retains original development ancestry, accepted
input digests/preimages, exclusions, approval/evidence records and each changed
file's mapping to this snapshot. None of those private records or objects is
part of publication. This new manifest does not refresh or replace a historical
freeze. Synthetic fixtures and unaffected module code remain intact.

Sanitation excludes private adoption/amendment/derived/validation/route records,
preserved root originals, historical freeze/preimage records and their private
intake/UX/packaging utilities. It replaces household-specific instructions,
host/audience/operator/recovery defaults and old baseline/install narratives
with generic scope and an unfilled typed deployment template. Root aliases name
only exact ordinary commands; the build uses the current publication verifier.
Ignore rules additionally cover vaults, recovery/backups, evidence/review,
transcripts, certificate bundles, archives and state. Ignore rules do not
authorize uploading a tracked private file.

All 33 designated sanitation paths have explicit dispositions in the external
ledger. Nine additional documentation paths received coordinator allocation.
A retained contract regression comment is generalized; its executable test body
is unchanged and unrun in ordinary CI.
Reviewed owner corrections are now integrated with executable and fixture
bytes preserved. New explicit source-presence admission remains blocked; no
atomic witness successor, provisional profile or private receipt is adopted.
New composition/preimage records and historical packagers are excluded; safe
technical documents describe the current behavior without private ancestry.
The private ledger maps both accepted inputs and the preserved intermediate
through each current adaptation. Final new-history audit remains required.
Later accepted module patches
follow docs/coordination/worker-handoff.md and receive their own exact mapping,
reviewed sanitation, affected ordinary checks and exact-tree audit.

Ordinary CI names six module builds, 14 valid history checks and one healthy
synthetic Request group, without stopped control execution. It pins official action revisions, Node/npm versions and dependency
locks, checks its exact event SHA and has contents:read only. It needs no secret,
deployment environment or household runner. Hosted execution remains unverified
until the exact reviewed SHA is separately released and pushed. Open-source
licensing is reserved for a future public-release decision.
