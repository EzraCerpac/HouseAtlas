# Saved native evidence original

The native drawing client has a host-owned optional `nativeEvidenceDocuments` prop on `TopologyProvider`. Main/Host composition must supply `createNativeEvidenceDocumentClient` with the current native session identity, immutable scope allocation, expiry, synchronous binding changes, canonical HTTPS origin and owned transport. Do not instantiate it from a stored evidence ID or browser storage. The port is absent until the host wires it; the existing evidence read remains available.

An explicit click on a current saved Atlas evidence record resolves its sole `atlas-asset` reference, re-reads the exact current Atlas asset, verifies original bytes with the existing native document client, and rechecks both records. The asset's reverse `evidenceIds` is not the correlation: native intake can leave it empty. Only an actual `image/png` asset with `safe-rendered` policy receives the bounded media `/preview` image and a revocable in-page URL. The transformed preview has no original-byte digest claim. PDF, JPEG, text and download-only PNG originals retain a download action after original-byte verification; no PDF inline viewer is inferred.

The UI closes and revokes its object URL on Close, Escape, unmount, evidence key change, session/scope replacement, expiry or native lease invalidation. The original download link lives only while that current frame is open. The button does not create a native record, file path, URL capability or evidence-confidence assertion. Actual electrical drawing intake and successful PNG renderer qualification remain separate acceptance evidence.
