# Native building geometry association source port

`createNativeGeometryAssociationClient` uses the host's canonical private session-owner identity, current session/scope/admission, and synchronous change notifications. It neither creates custody assets nor infers room placement or physical scale. The selected USDZ/authored mesh or IFC/GLB pair must already be separate committed, available, download-only Atlas assets. The selection carries the existing building identity ID and its actual accepted building-semantics record ID; no package UUID, source binding, or topology revision is treated as a guard.

`load` obtains current Stock `atlas.identity.get`, `atlas.location-semantics.get`, `atlas.asset.get` for each asset, and `atlas.evidence.get` for every ID referenced by either the identity or semantics. Every result is a closed schema-validated, single active record with matching target, scope, request ID, `sourceStatus: current`, and null cursor. Revision nodes remain `ExactDecimal`; an Atlas revision outside the published Stock schema's safe integer maximum is refused rather than rounded. The private host's canonical session-owner object, actor, CSRF, expiry and full workspace/home tuple define the local epoch. A missing admission masks the binding but does not clear an unresolved submitted intent.

`prepare` creates exactly three original Stock children in this order: `atlas.evidence.create` with owner-report/unknown provenance and ordered references to both assets; `atlas.geometry.create` with either the backend's Magicplan/USDZ profile or the distinct IFC/GLB profile, unknown physical coordinate units, null scale and transform, empty mappings, and sole new evidence ID; and guarded `atlas.identity.replace`, preserving every existing identity payload field and appending one evidence ID. The IFC geometry producer/export format is `ifc`/`ifc`, never `magicplan`/`usdz`. The root batch carries fresh current guards for the identity, accepted semantics, both assets and every pre-existing evidence record. Evidence and geometry children carry the required asset guards; identity replacement carries every pre-existing identity-evidence guard and the exact target revision. The backend association route independently checks the selected profile, current graph, custody bytes, derivative lineage, and atomic transaction preconditions.

The statement is bounded to 4096 Unicode code points. The mutation reason is bounded to the native Atlas mapper's 1024 Unicode code points before an intent can be prepared; neither field is clipped.

`commit` retains the full exact body before its one POST to the existing `/api/atlas/geometry/v1/.../buildings/{buildingId}/associations` route. It uses the current host CSRF token. A timeout, abort, HTTP error, malformed response, or lost response remains `unknown` in memory and blocks another load or prepare in that epoch. No automatic resend or negative-absence inference is made. A success requires the closed batch result schema, exact request/scope correlation, three ordered records and audit IDs, expected revisions and payloads (only the server-derived `importedAt` is excluded from geometry request payload comparison), and the native Stock owner’s root-only-exclusion JCS SHA-256 digest. This source port retains the submitted body and correlated receipt for inspection; it does not claim durable replay or restored unknown-state qualification.

After the asynchronous digest, both the outer bounded deadline/abort signal and the inner context signal must still be live before `committed` can replace the retained `unknown` row.

`frontend/src/numeric/schema-validator.ts` has the four closed map entries this port needs against its pinned generated schemas, with no wildcard expansion: `nativeRequests['atlas.asset.get'] = 'request_atlas_asset_get'`, `nativeRequests['atlas.geometry.create'] = 'request_atlas_geometry_create'`, `nativeRequests['atlas.identity.replace'] = 'request_atlas_identity_replace'`, and `nativeReads['atlas.asset.get'] = 'result_atlas_asset_get'`. The host must expose the same canonical session-owner identity used by the approved custody write port; a cloned session DTO or a locally minted identity cannot substitute for it.

The port has no product UI mount. The assistant scan import compiles it through `tools/geometry/native-scan-import-runtime.mjs`; the port added no HTTP route, backend schema or generated contract.
