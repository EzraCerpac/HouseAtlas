# Independent Media policy archive source

The running host captures process-local renderer provenance after successful
qualified upload and existing-asset review stock commits. Actual original bytes,
bounded stripped renderer output and opaque producer qualification remain
coupled to the exact native Asset record and stock/audit association. A policy
enum, MIME type, measured digest or serialized receipt cannot create that proof.
Missing legacy, restarted or unretained later lineage remains unavailable.

`MediaPolicyArchivePacket::encode_upload` and `encode_review` now retain these
actual producer facts in the closed `houseatlas-media-policy-archive/1` format.
They require the genuine opaque stage/review carrier and original mutation
guard. The transient packet retains the actual original principal allocation;
the serialized bytes contain comparison data. Actual successful native commit
authenticity stays with the host and mandatory archive write owner.

`NativeMediaPolicyArchive<W,R>` composes the actual opened private directory
descriptor with mandatory independent Media write/read owners. Before publication,
the write owner must authorize the exact destination, native origin/generation,
original producer and complete raw packet. Immutable publication uses the existing
file fsync, link and directory fsync mechanics. Postcommit archival failure cannot
imply SQL rollback or successful disclosure.

Select a dedicated preprovisioned Media-only directory. Member names are exactly
canonical native Asset audit UUIDs followed by `.media-policy.json`; HomeBox
`.producer.json` files and all unknown/pending members are unavailable. Local
try-lock and nonblocking descriptor flock cover both typed Media operations and
legacy native producer writes, including independently opened descriptors.
The full catalog is bounded to 10,000 members, 1 MiB per member additionally
limited by configured frame size, and 16 MiB total. Reads require mode-0600
regular current-euid files, no-follow descriptor-relative opens and stable full
pre/post enumeration, file identity, timestamps and exact bytes.

Strict decode validates native/request/binding/renderer correlations and exact
canonical packet bytes. It returns a separate offline evidence carrier borrowing
the same mandatory independent read owner. It reconstructs no renderer, stage,
review proof, principal or grant. The read owner must authenticate origin,
destination, generation, exact producer bytes and the complete native catalog
independently of the recovered image. Path permissions, hashes, names and packet
origin fields supply matching data, not this authentication.

`ArchivedMediaQueueEvidence` explicitly combines the caller's required original
Jobs attempt validator with an already authenticated Media archive collection.
Read and authenticate the full catalog before entering Storage. Its Media frame
callback reauthorizes the same original archive binding and checks an exact Asset
or full historical consumed-upload association without filesystem I/O, SQL,
Access or vault reentry. The composite creates no recovery permit and selects no
default origin policy.

The supplied production tree has no genuine configured Media origin/write/read/
catalog authorization implementation. These adapters therefore close the bounded
codec/custody/composition source seam while production archival capture and cold
startup remain unbound. No new signing key, source approval or historical proof
is inferred. Populated restore, archive maintenance and related controls remain
held; this source does not establish their readiness.

The explicitly named `healthy-recovery-policy-archive` example uses actual AT11
Access, a private synthetic 2×1 renderer, native Media runtime, a genuine Store
create and verified review commit, fsynced publication and a newly opened reader.
It drops the writer, live proof/principal, Access, vault and Store before matching
the offline Asset. An independently retained, expressly synthetic native owner
authenticates the bytes/catalog. This proves the fresh bounded mechanism, not
process-restart origin custody, production recovery or any held control.
