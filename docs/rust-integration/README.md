## Actual running core

The binary requires explicit disposable settings, creates private scratch state
under `/tmp` and binds TLS only to IPv4 loopback. It checks actual request
origin/authority and headers, derives the login client key from the connection
IP, bounds body streams, and passes original opaque authority to domain and
storage. Responses retain the private no-store/header adapter documented in
[read-corrections.md](read-corrections.md).

The binary establishes creation mask `0077` before starting runtime worker
threads. After creating the private disposable directory, the host supplies its
actual canonical directory identity to media and SQLite. System temporary-root
aliases preserve the owners' canonical-path, inode, no-follow, private-mode and
durability checks. Media startup errors identify only the fixture phase and
public error category, with no credentials or paths.

The root HTML supplies React's session/login/logout and scoped-view attributes.
Real React renders Home, Rooms & places, room/item details, Settings and successful
sign-out/sign-in. The host supplies a stable actual editing client across admission
refresh. The accepted owner UI exposes its Atlas place editor independently of
the passive HomeBox `canEdit` hint; classification still requires the returned
server admission. Its reason fields display and enforce 1024 Unicode code points
without clipping or relying on HTML's UTF-16 `maxLength`. The human-form healthy
runtime flow completes through the real HTTP editing client and preserves its
canonical receipt across refresh. Native WebMCP classification and canonical
React completion are demonstrated separately. The actual attachment client and
qualified multipart route are now bound; see [upload-preparation.md](upload-preparation.md).

The fixture provisions disposable viewer/editor users through real access APIs
with random passwords and salted scrypt verifiers. A mode-0600 scratch receipt
transfers credentials to the inspected healthy browser script; credentials,
cookies and CSRF never enter Git or emitted evidence. Both actual databases
reopen before HTTP. Initial state contains six published synthetic records,
two HomeBox projections and one cache in one home. Two public synthetic originals
are prepared in the real private vault; no asset record exists until its fresh
healthy command commits through the native runtime availability proof. No real
source, account, grant, media or household configuration is supplied.

NativeContracts delegates the full storage contract to the accepted domain
NativeSemantics adapter and exact shared contract owner, including raw-current
transition and finite timestamp exports. NativeScopedCommands and NativeStorage

original mutation authority and CSRF before bounded JSON parsing. Canonical and
stock mutation bodies are limited to 1 MiB. The parser preserves literal object
keys, rejects duplicate decoded keys and uses the reference root-depth-zero
limit of 64. It retains numeric values without f64 rounding, although serde may
normalize equivalent token spelling. Shared JCS and persisted canonical JSON use
the finite ECMAScript/f64 numeric model and its rounding boundary; see
[canonical numbers and timestamps](../../backend/src/contracts/semantics/README.md#canonical-numbers-and-timestamps).

replacement witness or source admission policy is supplied.
